# NOVA — Strategy Layer

## Strategic decisions
The player should eventually decide between competing uses of limited:
- land
- money
- labor
- energy
- materials
- transport capacity
- time

## Foundation
Strategy should emerge from constraints. Do not create arbitrary “strategy choices” before the underlying economy exists.

## Example
Choosing between expanding housing and building production should become meaningful only when both compete for scarce resources or create different future capacities.
