# NOVA — Core Loop

```text
PLAYER ACTION
  ↓
INFRASTRUCTURE
  ↓
CAPACITY / SERVICE
  ↓
COLONIST NEED
  ↓
CONSUMPTION / SATISFACTION
  ↓
BEHAVIOR / WORK
  ↓
PRODUCTION
  ↓
ECONOMIC ACTIVITY
  ↓
NEW DEMAND
  ↓
PLAYER ACTION
```

## First playable loop
Only housing exists initially.

```text
House built
→ construction complete
→ house operational
→ housing capacity = 1
→ colonist eligible
→ colonist arrives
→ colonist assigned to house
```

No food, water, electricity, jobs, money or vehicles are required in the first implementation slice.
