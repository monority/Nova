# NOVA — Economy

## Economy philosophy
Start with flows, not dozens of resources.

The economic model should answer:
- who produces?
- who consumes?
- what is exchanged?
- what limits production?
- what happens under shortage?

## Minimal future model
`household → labor → income → consumption`

`business/industry → goods/service → revenue`

`infrastructure → capacity → maintenance cost`

## Resource rule
Every resource must have:
1. producer
2. consumer
3. reason to exist
4. storage/flow semantics
5. failure consequence
