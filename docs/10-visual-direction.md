# NOVA — Visual Direction

## 1. Visual Thesis

NOVA should look like a **living digital architectural model**.

It should be closer to:

```text
generative art
+
architectural visualization
+
scientific visualization
```

than to a conventional city-builder.

## 2. Core Principles

- dark negative space;
- restrained geometry;
- precise silhouettes;
- controlled illumination;
- limited palette;
- subtle motion;
- readable density.

## 3. Avoid

- cyberpunk overload;
- excessive bloom;
- giant neon signs;
- holographic HUDs;
- generic sci-fi gradients;
- photorealistic textures;
- noisy procedural detail.

## 4. City Materials

Buildings should use simple materials with controlled variation.

Variation can affect:

- height;
- width;
- setback;
- facade pattern;
- window density;
- illumination.

## 5. Roads

Roads are represented by geometry plus subtle light flow.

Traffic is represented by moving points/lines rather than realistic cars in the MVP.

## 6. Lighting

Lighting hierarchy:

```text
World ambient
→ terrain
→ buildings
→ infrastructure
→ active flows
→ selected objects
```

Selected objects should be clearer without becoming glowing outlines.

## 7. Night

Night increases:

- window visibility;
- infrastructure illumination;
- traffic readability.

Night must remain elegant rather than neon-heavy.

## 8. Animation

Motion should communicate systems:

- construction;
- traffic;
- energy flow;
- population growth;
- environmental movement.

Avoid decorative motion without semantic meaning.

## 9. Camera

Orthographic camera in a strict zenith/top view. The world must read as a contemporary planning model, not an isometric miniature.

Support:

- pan;
- smooth zoom;
- optional rotation only if it preserves the top-down reading;
- focus on selection.

## 10. Visual Progression

Early civilization:

```text
sparse
low
quiet
```

Late civilization:

```text
dense
vertical
connected
luminous
complex
```

Complexity must emerge through systems, not visual clutter.
