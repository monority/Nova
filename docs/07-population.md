# NOVA — Population

## Colonist model
A colonist is an agent with:
- stable identity
- residence
- needs
- employment status
- basic economic state later
- deterministic state updates

## First implementation
One colonist is enough.

The first colonist should appear only when a valid housing capacity exists.

## Population growth
Long-term population growth should be caused by settlement viability, not a free timer.

Potential future conditions:
- housing availability
- food availability
- water availability
- power/service availability
- employment/income
- transport/accessibility
- quality of life

These are not all required simultaneously for the MVP.
