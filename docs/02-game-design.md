# NOVA — Game Design

## Player role
The player is the settlement planner/operator. They create infrastructure and make decisions; agents execute daily life inside the resulting system.

## Core interaction
The player builds, connects, enables and expands. Simulation consequences appear over time.

## Foundation loop
1. Establish a buildable location.
2. Construct housing.
3. Make housing operational.
4. Provide capacity for residents.
5. Admit a colonist.
6. Colonist generates needs.
7. Needs require services/goods.
8. Services require infrastructure and production.
9. Production requires labor and inputs.
10. Labor creates economic activity.
11. Growth creates new demand.

## Design test
Whenever a mechanic is proposed, answer:
- Who needs it?
- What provides it?
- What does providing it consume?
- What happens when it is unavailable?
- Which visible world/UI element communicates this?
