# NOVA — World & Terrain

## Terrain role
Terrain is a constraint and opportunity layer, not merely a visual backdrop.

Early terrain variables should remain minimal:
- buildability
- slope/elevation
- water presence/access
- resource potential later
- transport cost later

## Rule
A terrain feature should matter only when a simulation system consumes it.

## Visual principle
Terrain remains dark, quiet and legible. Infrastructure provides most of the visual structure.
