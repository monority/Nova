# NOVA — Technology

## 1. Purpose

Technology changes what the civilization can do and how it looks.

Technology must not be a decorative skill tree disconnected from the simulation.

## 2. Eras

```text
Survival
→ Agriculture
→ Engineering
→ Industry
→ Electricity
→ Science
→ Computing
→ AI
→ Autonomous Systems
```

## 3. Technology Structure

```ts
interface Technology {
  id: string
  prerequisites: string[]
  researchCost: number
  effects: TechnologyEffect[]
}
```

## 4. Effects

Effects can modify:

- production;
- infrastructure capacity;
- building types;
- transport;
- energy efficiency;
- research speed;
- automation.

## 5. Research

Knowledge is generated by:

- schools;
- universities;
- research facilities;
- advanced institutions.

Research progress is continuous.

## 6. Visual Transformation

Technology should introduce visible changes.

Examples:

```text
Electricity
→ lighting + power infrastructure

Computing
→ data networks + new architecture

AI
→ autonomous transport + automated infrastructure
```

## 7. Research Choice

The player chooses research priorities.

Later, autonomous policies may allow the civilization to select technologies automatically.

## 8. Avoiding a Traditional Tech Tree

Do not fill the interface with dozens of tiny nodes.

Prefer a small number of meaningful technologies with strong systemic effects.

## 9. Technology History

Completed technologies are recorded permanently in the civilization timeline.

## 10. MVP

The player-facing technology tree is post-MVP. During the MVP, technology is limited to deterministic placeholder counters and milestone events so the simulation contract can reserve the correct state boundary without adding a second progression system.
