# NOVA — UX & Interface

## Principle
The world is the primary interface. UI explains what the world cannot show directly.

## Selection inspector
When selecting a building/colonist, show:
- identity
- state
- capacity
- current use
- requirements
- problems
- relevant connections

## Global HUD
Keep it small:
- date/time
- simulation speed
- population
- essential economy/service indicators once they exist

## Feedback
A player should be able to answer quickly:
- What is this?
- Is it working?
- Who uses it?
- What does it require?
- What is blocking it?
