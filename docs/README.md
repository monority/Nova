## Product Rule

> The player draws the rules. The simulation draws the city.

## Source of Truth

The [Product Contract](./20-product-contract.md) is authoritative for MVP scope, simulation units, progression thresholds, persistence, performance budgets and acceptance gates. Older documents explain intent and design direction; they must not override the contract.

## Development Rule

Build the smallest beautiful vertical slice first. Do not expand the simulation before the core city is visually and systemically compelling.
