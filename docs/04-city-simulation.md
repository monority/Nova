# NOVA — City Simulation

## City as a system
A city is not a collection of buildings. It is a network of:
- residents
- buildings
- services
- production
- infrastructure
- movement
- land
- time

## Growth principle
Physical growth should follow demand and available capacity, not a generic population timer.

A useful long-term pattern is:

`demand → investment → capacity → usage → growth → new demand`

This is consistent with established simulation/transport designs where town growth, buildings, roads, cargo and services interact rather than existing as independent counters. ## NOVA simplification
NOVA should not reproduce OpenTTD's mechanics. It uses the same broad principle: growth must be explainable through interacting systems.
