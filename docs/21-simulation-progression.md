# NOVA — Simulation Progression

## Progression order
```text
Housing
→ Population
→ Needs
→ Services
→ Food / Water / Power
→ Work
→ Money
→ Production
→ Transport
→ Urban growth
→ Technology
→ Larger systems
```

## Dependency rule
A later system may not become a prerequisite of an earlier system unless the earlier system has explicitly been revised.

## Complexity budget
Introduce one new causal dimension at a time.
