## 1. Synthèse exécutive

NOVA est un city-builder/civilisation-builder 3D stylisé, **complet sur
tout le MVP documenté** (roadmap phases 0-10, trois âges jouables) et
au-delà : événements contrôlés tunés et sûrs, première mécanique de
logistique par distance, 316 tests unitaires + 34 E2E verts, CI
complète. La période du 30 octobre au 2 novembre 2026 (Steps 045-052,
23 commits) a livré : un audit complet et sa remise en ordre, le
dernier système du MVP (événements), deux campagnes de mesure qui ont
**trouvé et fermé trois pièges économiques avant qu'un joueur ne les
rencontre**, la logistique v1 calibrée, une passe documentaire et le
premier playtest sur UI réelle. Le seul input encore manquant est une
session de jeu humaine.

## 5. Le pattern du projet : trois pièges trouvés par la mesure

C'est peut-être la valeur la plus durable de la période — la doctrine
« mesurer avant de tuner » a fonctionné trois fois :

1. **Step001 (pré-reboot, conservé en mémoire)** : la baseline économique
   était structurellement non viable (revenu 3 vs entretien 3-4) — corrigé
   par la colonie D2 (Step021) ;
2. **Step048** : l'expiration d'un bonus de récolte sur une colonie à
   marge zéro effaçait 24 habitants → règle d'or : **aucun événement ne
   gonfle un taux de production** (P1') ;
3. **Step050** : toute pénalité absolue de distance sur les producteurs de
   subsistance brise soit l'ouverture D2 (géométrie ancre/colonie), soit
   la ligne de croissance (plafond de fermes × rendement pénalisé) →
   efficacité restreinte à l'extraction, V2 logistique re-cadrée.

À chaque fois : le garde-fou a détecté, la mesure a expliqué, le cadrage
a été amendé avec la preuve, le test permanent verrouille.

## 6. Décisions de design majeures (ADR + cadrages approuvés)

- **ADR-001/002/003/004** : simulation indépendante du rendu, tick fixe
  déterministe, logistique et population agrégées (pas d'agents) ;
- **ADR-005** : génération du monde seedée (rejouable) ;
- **ADR-006** : persistance versionnée à migrations strictes ;
- **ADR-007** : événements = fonction pure (seed monde, occurrence) ;
  amendé Step049 (pas de hausse de taux, manne one-shot) et Step050
  (taper, mi-socle) ;
- **Cadrages approuvés** : D1-D5 (événements), P1-P3 (tuning),
  L1-L5 (logistique) — chacun avec ses amendements de calibration
  documentés dans les addenda des reports.

## 8. Ce qui est possible — les six portes ouvertes

1. **Triage Step052** (quick wins UI F4/F6/F7 + lisibilité pollution
   F1/F5) : petite slice prête, ~1 h, aucun changement de mécanique ;
2. **V2 logistique** : stockage par réseau (SAVE_VERSION 19), taxation
   fermes/puits/ateliers, congestion — fondations BFS posées, cadrage à
   refaire (reporté Step050) ;
3. **Événements conditionnels** (smog sur pollution haute, curseur
   d'intensité) — sous la règle « jamais de hausse de taux » ;
4. **Visuel V2-V3-V5** : architecture par âge, habitants visibles,
   ombres/emissive (cadrage Step042 §2, décisions artistiques + mesure
   perf) ;
5. **Contenu Âge 4+** : nouvelle mécanique à définir (gros cadrage
   produit) ;
6. **Volet B — ta session de jeu** (kit Step048) : l'input
   irremplaçable qui arbitre toutes les priorités ci-dessus.

## 9. Ce qui manque / limites assumées

- **Logistique PARTIAL** : fermes/puits/ateliers non taxés (décision de
  calibration documentée — preuve famine farm-cap), ni congestion ni
  capacité ;
- **Overlay logistics peu parlant en pratique** : la colonie D2 n'a
  aucun chantier d'extraction, l'overlay ne montre que les hubs ;
- **Événements** : pas de conditionnels ni de curseur d'intensité
  (reportés assumés du cadrage) ;
- **Fin de contenu** : rien après l'Âge 3 — une partie « se termine »
  vers 1 500 ticks ;
- **Ressenti humain absent** : esthétique, rythme perçu, difficulté —
  le playtest d'agent ne remplace pas le joueur ;
- **Divers** : alerte staffing permanente (bruit), monde de test 16×16
  (la logistique n'y mord que sur l'extraction lointaine).
